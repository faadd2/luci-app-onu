# 软话机拨号键盘设计参考（2026-10-19 收集）

> 目的：为 ONU>语音>软话机 键盘重写提供样式与实现参考。当前实现（`voice.js buildKeypad` + `onu.css .onu-keypad`）
> 用 `<table>` 布局，与 LuCI 全局 `table` 元素规则（width:100%、border-top !important、隔行底色）反复冲突，
> 已出现三次「缩成一团/横线/不对齐」返工——**结论：放弃 table，改 div+CSS Grid**。

## 参考一：Twilio 官方拨号键盘教程（iOS 风格，推荐主参考）

来源：https://www.twilio.com/en-us/blog/ui-dialpad-javascript-programmable-voice-quickstart

要点：
- 数字键 = 大号数字 + 小号字母副标（2 ABC / 3 DEF…）的经典电话布局
- 按键 `.digit` 固定宽 30px + padding，float 排三列；`:active` 变底色给按压反馈
- 呼叫键绿色圆形（#66bb6a）、挂断键红色（#ec2f0e），悬停/按压有状态色
- 结构：`form > input + 4 行 .row（各 3 个 .digit）+ .botrow(+/拨打/挂断/退格)`

核心 CSS：
```css
.digit { float:left; padding:10px 30px; width:30px; font-size:2rem; cursor:pointer; }
.sub   { font-size:0.8rem; color:grey; }
.digit:active { background-color:#e9e9e9; }
#button-call  { background:#66bb6a; }  /* 绿 */
#hangup       { background:#ec2f0e; }  /* 红 */
```

## 参考二：jsSIP 软话机（Bootstrap 网格，结构最简）

来源：https://gist.github.com/paulgrammer/444260760898ec573cfff6bd99a42f68

要点：
- 3 行 × `col-4` Bootstrap 网格，每键 `btn btn-outline-dark btn-block`
- 外层限宽居中：`col-7 offset-2 col-md-4 offset-md-4`（手机窄、桌面更窄居中）
- 按键事件委托：`.dialpad-btn` click 读 `event.currentTarget.text()` 送 DTMF
- DTMF 与输入框分离：键盘同时驱动「号码输入」和「通话中 DTMF」两个用途

## 参考三：CSS Grid 通用布局模式（本项目落地选型）

来源：https://blog.logrocket.com/creating-responsive-web-layouts-with-css-grid/ 等

落地写法（3 列等宽、自动换行、免媒体查询）：
```css
.onu-keypad-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 0.5rem;
  max-width: 16rem;
}
```
比 table 的优势：不继承 LuCI 全局 table 规则、等宽由 grid 保证、*0# 第四列变体只需
`grid-template-columns: repeat(4, 1fr)` 或 `grid-column` 指定。

## 我们的设计定稿（待用户确认后实施）

- **布局**：`<div class="onu-keypad-grid">` 3 列 Grid，标准电话序 1-9 / *0# 末行
  （放弃此前的「*0# 竖排第 4 列」非常规布局——Grid 下常规 3×4 已整齐，非常规排法失去意义）
- **键样式**：圆形键（border-radius:50%）、直径 3.2rem、数字 1.2rem 居中 +
  可选字母副标 0.6rem（仿 iOS）；底色用 Argon 变量 `var(--secondary, #f6f9fc)`、
  按压 `:active` 加深；与 onu.css 现有令牌体系一致
- **功能行**（键区下方独立一行）：退格⌫（左）· 拨打（中，绿色圆键，通话中变红色挂断）· 加 0（右，可选）
- **通话中**：键盘转 DTMF 模式（jsSIP 参考二的委托写法），键区底色不变、数字键发 DTMF 音
- **CSS 落点**：规则写在 onu.css（继续避开 LuCI table 战争，div 无全局样式冲突）
- **验收**：12 键等距对齐、无横线/边框、字符居中、Argon 暗亮色都正常、窄屏（手机 LuCI）不挤压
